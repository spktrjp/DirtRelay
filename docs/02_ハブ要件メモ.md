# ハブアプリ 要件メモ

アプリ名: **DirtRelay**（2026-11-04 決定。旧仮称 SuperDirt-SynthApp）。オーナーとのやり取りで決まったことを時系列で記録する。

## 構成（2026-11-04 時点の合意）

```
ORCA ;04C ──UDP 49161──▶ ハブ（Node.js）──OSC bundle──▶ SuperDirt :57120
                           ▲ WebSocket
                      GUI（ローカルWeb → 後でElectron等）
```

- 入力: ORCA `;` の文字列を主入口とし、先頭1文字をスロット番号にする（Pilot 互換）。`=`（整数OSC）・MIDI は後で追加
- スロット: 0〜f（16）。0〜z（36）への拡張余地を残す
- 既定プリセット: 0〜f に SuperDirt シンセを割り当てる（案は下記）。GUI から差し替え可能
- 出力: `/dirt/play` を bundle＋固定レイテンシで送る（01_SuperDirt受信仕様.md §3.1）

### G4: アプリが受け持つパラメータ（案）

| 区分 | 中身 | どこで実現するか |
|---|---|---|
| 音ごとのエフェクト | `cutoff`/`resonance`（LPF）、`hcutoff`（HPF）、`bandf`/`bandq`（BPF）、`vowel`、`shape`、`crush`、`coarse`、`attack`/`release`、`tremolorate`/`depth`、`phaserrate`/`depth`、`psrate` | SuperDirt。スロットの既定値として毎イベントに付与 |
| orbit 共有エフェクト | `delay`/`delaytime`/`delayfeedback`（`lock` でテンポ同期）、`room`/`size`、`leslie` | SuperDirt。orbit 単位のミキサー的画面も検討 |
| 再生の制御 | `speed`、`begin`/`end`、`accelerate`、`legato`/`sustain`、`cut`、`pan`、`gain` | SuperDirt |
| Tidal 側の機能（SuperDirt には無い） | 時間変化（LFO・エンベロープでパラメータを動かす）、確率で間引く（`degrade`/`sometimes`）、ランダム化、左右に振り分け（`jux` 風）、n 回に1回だけ変える（`every` 風） | **アプリ側で実装**（送出時に値を計算） |
| ライブ操作 | 画面のノブ／フェーダー、MIDI コントローラの割り当て、ORCA `=` の整数をパラメータに写像 | アプリ側 |

### パラメータの既定（2026-11-04 決定事項の案）

- 各パラメータの初期状態は **「未設定＝送らない」**。Tidal と同じく、書いたもの（設定したもの）だけを送る
  - `cutoff` 未設定 → フィルター自体が挿入されない（素通し）。`resonance` だけ設定しても `cutoff` が無ければ効かない
- 階層: 共通デフォルト（全スロット）→ スロット個別で上書き。未設定はどの階層でも「送らない」
- `room`/`size`/`delay` 系は orbit 共有で、しかも key を含まないイベントが来るとオフに戻る（01 §4.6 実測）
  → **スロットではなく orbit の設定として持ち、その orbit 宛の全イベントに自動で付与する**

### （旧）1スロット1画面のたたき台 ※G1' により不採用。編集画面の中身として流用

- 上部: スロット番号（大きく）、割当中の音源名、orbit、直近の発火インジケータ
- 左: 受信モニタ（最新N件、時刻・生文字列・解釈結果）
- 右: アサイン編集（音源、n、orbit、gain/pan/cutoff/room/legato、ノートの扱い）
- 下: 送出モニタ（実際に送った `/dirt/play` の key/value）
- 変更はその場で反映（次の受信から適用）。プリセット保存は別操作
